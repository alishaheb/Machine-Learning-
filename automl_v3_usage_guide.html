AutoML Pipeline v3.0 — Usage guide

Self-healing, feature stories, drift sentinel, adversarial stress testing

Step 1 — Install
pip install pandas numpy scikit-learn xgboost lightgbm matplotlib seaborn shapcopy
Step 2 — Run everything
This runs both classification + regression, self-healing, stress testing, and feature stories — all at once.
python auto_ml_pipeline.py --data your_data.csv --target target_column --task both --allcopy
Step 3 — Check results
All outputs land in the pipeline_output/ folder:
model_comparison_*.png — visual ranking of all models
confusion_matrix_*.png — classification accuracy grid
actual_vs_predicted_*.png — regression scatter plot
shap_importance.png — why each feature matters
feature_story.txt — plain-English explanation
stress_test_report.png — robustness gauge + attack results
cross_task_insights.png — feature importance across tasks
healing_strategy_comparison.png — which strategy won
data_fingerprint.json — baseline for future drift checks
best_model.pkl — saved model ready for production
Auto-detect (simplest)
Pipeline figures out if it's classification or regression based on your target column.
python auto_ml_pipeline.py --data data.csv --target price
Force classification
python auto_ml_pipeline.py --data data.csv --target label --task classification
Force regression
python auto_ml_pipeline.py --data data.csv --target price --task regression
Dual mode both at once
Runs classification AND regression simultaneously. For continuous targets, it auto-bins into classes. For categorical targets, it encodes to numeric.
python auto_ml_pipeline.py --data data.csv --target price --task both
Clustering (no target)
When you don't have a target column — finds natural groupings in your data.
python auto_ml_pipeline.py --data data.csv
Self-healing new
Tries 7 different preprocessing strategies (imputers, scalers, feature engineering levels) and picks the best one automatically.
python auto_ml_pipeline.py --data data.csv --target col --heal
Adversarial stress testing new
Attacks your model with noise, missing data, outliers, and feature shuffling. Reports a robustness score 0–100.
python auto_ml_pipeline.py --data data.csv --target col --stress
Feature story new
Generates a plain-English narrative explaining why each feature matters using SHAP analysis.
python auto_ml_pipeline.py --data data.csv --target col --story
All modules combined
python auto_ml_pipeline.py --data data.csv --target col --task both --all
Mix and match
You can combine any flags freely:
python auto_ml_pipeline.py --data data.csv --target col --heal --stress
Step 1 — Train your model (creates baseline automatically)
When you run the pipeline, it saves a data_fingerprint.json capturing the statistical profile of your training data.
python auto_ml_pipeline.py --data train.csv --target price --all
Step 2 — Later, check new data for drift
Compare new incoming data against the saved baseline. Detects distribution shifts, new categories, missing pattern changes, and schema changes.
python auto_ml_pipeline.py --monitor --baseline pipeline_output/data_fingerprint.json --new new_data.csv
What it checks
Numeric drift — Kolmogorov-Smirnov test per feature
Categorical drift — new or vanished categories
Missing patterns — rate changes above 10%
Schema changes — added or removed columns
