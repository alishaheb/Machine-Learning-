# ML
# Large-Scale Machine Learning Experimentation Repository

## Overview

This repository is a systematic exploration of machine learning models across a wide range of datasets and problem types.  
The goal is **learning through experimentation**, not leaderboard chasing.

More than **100 machine learning models** are going to be trained, evaluated, and compared using **diverse datasets** to understand:

- Model behaviour across different data distributions
- Strengths and weaknesses of algorithms
- The impact of preprocessing, feature engineering, and hyperparameters
- Trade-offs between performance, complexity, and interpretability

This repository serves as a **personal research lab and learning reference**.

---

## Objectives

- Apply classical and modern ML models to many datasets
- Build intuition for *why* models succeed or fail
- Compare algorithms under consistent experimental settings
- Practice reproducible ML experimentation
- Create a long-term reference for future projects

---

## Experiment Scope

### Models (100+ total)
Includes but is not limited to:

- Linear Models  
  - Linear Regression, Logistic Regression, Ridge, Lasso, ElasticNet

- Tree-Based Models  
  - Decision Trees, Random Forests, Extra Trees

- Boosting Algorithms  
  - XGBoost, LightGBM, CatBoost, AdaBoost, Gradient Boosting

- Support Vector Machines  
  - Linear, Polynomial, RBF kernels

- Probabilistic Models  
  - Naive Bayes variants, Bayesian Regression

- Neural Networks  
  - MLPs, shallow neural architectures

- Unsupervised Models  
  - K-Means, DBSCAN, Hierarchical Clustering, PCA, Autoencoders

- Ensemble and Hybrid Approaches
